FAQ

Before you start.

Do guests need an app?

No. They scan the table QR code and use the web menu directly in the browser.

Can restaurant owners edit their own menu?

Yes. Each paying owner signs into a private dashboard protected by Supabase authentication and Row Level Security.

What happens if a subscription stops?

The dashboard becomes locked while the restaurant data remains stored, so the account can be restored after renewal.

Can I change prices later?

Yes. The monthly recurring prices live in Stripe, while the one-time setup fee is added by the PlateView checkout. Both can be changed later.
